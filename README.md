# 💍 Casamento Enthony & Alana

Site oficial desenvolvido para o casamento de Enthony e Alana. O projeto foi criado com o objetivo de proporcionar uma experiência elegante, fluida e totalmente responsiva aos convidados, reunindo todas as informações essenciais do evento e facilitando o envio de presentes.

---

## ✨ Funcionalidades

* **Capa Imersiva (Hero Section):** Seção de destaque exibindo a citação especial de Santa Terezinha do Menino Jesus e a foto de entrada lado a lado no desktop, adaptando-se perfeitamente para telas menores.
* **Contagem Regressiva:** Exibição dinâmica dos dias, horas, minutos e segundos restantes para a data do casamento.
* **História dos Noivos:** Seção dedicada a contar a trajetória do casal com fotos estilizadas.
* **Cerimônia e Recepção:** Informações completas sobre o local da cerimônia (*Paróquia Santa Terezinha do Menino Jesus*) e da festa (*Espaço Nobre Cascavel*), com links e integração direta para o Google Maps.
* **Lista de Presentes e Pix:**
  * Botão flutuante direcionando para a lista de presentes oficial na Havan.
  * Modal interativo com QR Code e chave Pix do tipo "copia e cola", com feedback visual imediato de confirmação.
* **Design Responsivo:** Interface otimizada para computadores, tablets e smartphones utilizando CSS Flexbox e *Media Queries*.
* **Rodapé Personalizado:** Créditos de desenvolvimento e marca registrada dos direitos autorais.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando tecnologias web fundamentais (Vanilla), sem o uso de frameworks pesados, visando alto desempenho, leveza e acessibilidade:

* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização, layout responsivo com Flexbox, sombras e variáveis de cor.
* **JavaScript (ES6+):** Lógica da contagem regressiva, controle do modal do Pix e funcionalidade de copiar a chave.
* **Google Fonts:** Tipografia do projeto (`Inter`).

## 🚀 Como Executar o Projeto

1. Clone este repositório:
   ```bash
   git clone https://github.com/Enthony-Oliveira/Casamento.git
   ```

2. Acesse a pasta do projeto no seu terminal:
   ```bash
   cd Casamento
   ```

3. Abra o arquivo `index.html` em qualquer navegador da sua preferência (ou utilize a extensão **Live Server** no VS Code).
